## 🎨 Customização

### Alterar Cores

Em `css/style.css`:

```css
:root {
  --primary: #242424;
  --secondary: #C4F4FF;
  --accent: #00E5FF;
  --text: #FFFFFF;
}
```

### Adicionar Seções

Crie novos divs com classes BEM:

```html
<section class="nova-secao">
  <div class="nova-secao__container">
    <!-- Conteúdo -->
  </div>
</section>
```
